# CircleOpenSearch
- CircleOpenSearch is a Circle-to-search opensource analog. It have Google Lens, Color Picker, Shazam (search music which is playing on your device or outside). And of course you can circle something from your screen to search it.
- Made with AI
- It works as assistant, so you can set it to the power button long press. And if you setup it like this, you could also open it through quick settings. Probably I will ad shortcuts in future, so you could run it through Key Mapper idk.

### Why not Circle-to-search?
I dont like this white line in the bottom of the phone (I can run Color picker only by holding it). And I also wanted a color picker.

### How to use it?
- Tap to the middle button to send entire screenshot to the Google Lens
- Tap to the left button to search song playing on your device
- Hold the left button to search song playing outside
- Tap to the right button to enter color picker mode.
- In color picker mode tap to the big circle to copy the color
- Circle somewhere on screenshot to search it in Google Lens

To activate CircleOpenSearch as assistant, go to Settings -> Apps -> Default apps -> Digital assistant app -> Select Circle Open Search
